eSewa Payment Gateway

This module integrates the eSewa payment gateway with Odoo, allowing you to accept payments via eSewa's ePay v2 API.

Testing Status

This module has been thoroughly tested and verified working with eSewa's test environment using test credentials. All core payment flows function correctly in the sandbox environment.

Note: While the module is fully functional in test mode, live environment testing with production credentials is pending. The module is expected to work seamlessly in production, but we recommend thorough testing in your specific setup before going live.

If you encounter any issues, please reach out and I'll be happy to assist with troubleshooting.

Features

  • Seamless eSewa payment integration
  • Secure payment processing
  • Automatic transaction status updates
  • Support for multiple currencies
  • Test and live environment support

Installation

Install this module like any other Odoo module. After installation, configure your eSewa merchant credentials in the payment settings.

Configuration

Go to Accounting > Configuration > Payment Providers and select eSewa. Enter your:

  • Merchant ID
  • Secret Key
  • Environment (Test/Live)
